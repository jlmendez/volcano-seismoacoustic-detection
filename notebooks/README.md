# Seismo-acoustic analytical notebook

The large source notebook contains the research workflow behind seismic-acoustic explosion detection at Volcán de Fuego. To keep the public portfolio reproducible and data-safe, the implementation is decomposed into filtering, feature extraction, K-Means candidate selection, cross-correlation validation and spectral diagnostics.

`seismoacoustic_pipeline_demo.ipynb` runs the architecture on synthetic coupled events. The original observational MiniSEED and institutional catalog data are not included.
